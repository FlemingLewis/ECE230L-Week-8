## Lab Questions

### In plain English describe the function and use of a multiplexer.
    Multiplexors are junctions. They select one input and ignore the rest. They in circuits to help with memory and data flow. A real world example is something with one input and many possible outputs but only one correct one. Such as decieding which key opens a specific lock.
### In plain English describe the function and use of a demultiplexer.
    A demulipexer is the inverse of a multiplexer, it splits one data flow into many individual outputs. Decompressing one signal into multiple different wires. An example of this would be a 2 bit input into 4 seperate wires. The signal would tell you which output is correct. A demultiplexer would determine if each indiidual output is true or false.
### What other uses might these circuits have? (Think Shannon’s)
    Both multiplexer and demultiplexer are useful interally for circuits. They are especially good for determining user input. For multiplexers are good for compression on audio and video to have more efficent use of bandwidth. And a specific use for demuliplexors is data routing.
